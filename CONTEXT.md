# Mr Papaya

Experimental Go CLI for learning mature open-source setup.

## Language

**Module**:
The Go import path `github.com/zzacong/mr-papaya`.
_Avoid_: package, library

**Repo**:
The GitHub repository at `zzacong/mr-papaya` that hosts the module.
_Avoid_: project, source

**Binary**:
The compiled `mr-papaya` command that prints a greeting.
_Avoid_: tool, app, executable

**Release**:
A tagged version plus built binaries published on GitHub.
_Avoid_: deploy, publish, version bump

**Version**:
Semver tag like `v0.1.0` that selects what `go install ...@<version>` fetches.
_Avoid_: revision, build number
